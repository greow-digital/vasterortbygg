## Sidkarta

### 1. Startsida (`/`)

**Sektioner i ordning:**

1. **Hero** — kort headline + USP-trippel (28 år · BKR-behörig · AAA-rating) + CTA (offert)
2. **Tjänster i grid** — 6 kort: Badrum, Kök, Totalrenovering, Stambyte, Fastighetsservice, BRF
3. **Aktuella projekt** — 4–6 senaste case (drar in från projektarkiv)
4. **Så jobbar vi (process)** — 4–5 steg ikonbaserat
5. **Kundtyper** — fyra spår med länk till respektive målgruppssida
6. **Behörigheter och medlemskap** — logobar med tooltip-förklaringar
7. **Recensioner / social proof** — Google-omdömen + utvalda citat
8. **CTA-band** — "Få en kostnadsfri offert"
9. **Område-block** — "Vi arbetar i hela Storstockholm" + lista över kommuner

### 2. Tjänstesidor (`/tjanster/...`)

Egen sida för varje huvudtjänst. Mall per sida:

- H1 + intro
- Vad ingår (lista)
- Process (3–5 steg specifikt för tjänsten)
- Materialval / leverantörer
- Tidplan (riktning)
- Pris (riktpriser + faktorer)
- Behörigheter relevanta för tjänsten (t.ex. BKR på badrum)
- 3 relevanta case
- FAQ (4–6 frågor)
- CTA: offert

**Huvudtjänster (egen URL):**

- `/tjanster/badrumsrenovering`
- `/tjanster/koksrenovering`
- `/tjanster/totalrenovering`
- `/tjanster/stambyte`
- `/tjanster/fastighetsservice`
- `/tjanster/brf` *(paketsida för BRF)*
- `/tjanster/kontorsanpassning`

**Övriga tjänster (gruppsida eller korta sidor):**

- `/tjanster/tillbyggnad` (uterum, garage, altan, takkupa)
- `/tjanster/snickeri` (fönster, dörrar, golv, inredning)

### 3. Målgruppssidor

Egna landningssidor som binder ihop relevanta tjänster + relevanta case.

- `/for-privatpersoner`
- `/for-brf` — referenser: Brf Målet i Vällingby, Brf Planeten 234
- `/for-fastighetsagare` — referenser: Brostaden, Klövern, Tage Liljedals
- `/for-foretag` — referenser: Opus, Rörbolaget, Stavdal

### 4. Projekt / Referenser

- `/projekt` — översikt med filter (typ, plats, år, omfattning)
- `/projekt/[slug]` — individuella case med:
  - Hero-bild + plats + år
  - Omfattning (kvm, tid, budgetspann)
  - Beställare (med citat om möjligt)
  - Materialval (leverantörer som länkar)
  - Bildgalleri (före/efter där det finns)
  - Relaterade case

**Förslag på första 8 case att producera** (baserat på Instagram-flödet):

1. Badrumsrenovering Kälvesta (kakel + kalksten + ek-möbler)
2. Köksrenovering Sundbyberg (IKEA + Järfälla Kök)
3. Totalrenovering villa — kök + badrum + gästrum + WiC (återkommande kund)
4. Mindre badrum / WC-ombyggnad (60-tals WC → ny dusch)
5. Badrumsrenovering lägenhet Solna (färgaccent på vägg)
6. BRF-stambyte (med samordning av boende)
7. Kontorsanpassning (lämplig referens från Opus/Rörbolaget/Stavdal)
8. Tillbyggnad / altan i villa

### 5. Process (`/process`)

Förklara hur ett projekt går till från första kontakt till slutbesiktning.

1. Kostnadsfritt möte / hembesök
2. Offert + tidplan
3. Avtal (AB / KTjL)
4. Genomförande med namngiven kontaktperson
5. Slutbesiktning + kvalitetsdokument (BKR bilaga A för våtrum)
6. Garantibesiktning

### 6. Behörigheter och garantier (`/garantier`)

Samlingssida — sätter rampljuset på det företaget är starkast på.

- BKR / PER (egen pedagogisk text — använd verbatim från nuvarande sajt)
- ID06
- Byggföretagen
- Stockholms Byggmästareförening
- AAA-rating
- ROT-avdrag (hur fakturan ser ut)
- Reklamationsrätt och dolda fel

### 7. Pris och ROT (`/pris-rot`)

- Hur en offert byggs upp
- Vad styr priset på ett badrum / kök
- Riktpriser per typ av projekt (spann, inte fasta priser)
- ROT — hur det dras direkt på fakturan
- Räkneexempel

### 8. Om oss (`/om-oss`)

- Historia (28 år, från 1998 / verksamhet 2005)
- Daniel + teamet (gärna med bilder och korta intro per snickare)
- Värderingar / kvalitetspolicy
- Behörigheter (kort + länk till garantisidan)
- Karta + besöksinformation

### 9. Karriär (`/karriar`) — om aktuellt

Företaget rekryterar (Instagram-post om "Enzo" som välkomnas). Lägg upp om de vill ta emot spontanansökningar.

### 10. Kontakt (`/kontakt`)

- Telefon + e-post (klickbara)
- Adress + karta
- Öppettider (saknas idag — fyll i)
- Offertformulär med fält:
  - Namn
  - Telefon
  - E-post
  - Typ av projekt (dropdown med tjänster)
  - Plats / kommun
  - Önskad starttid
  - Fri text
  - Filuppladdning (planritning, bilder)

Long-tail-trafikspår. Se [`vasterortsbygg-seo.md`](vasterortsbygg-seo.md) för rubrikförslag.

- Canonical-taggar
- Lazy-loading på bilder
- WebP/AVIF med fallback
- Klickbar telefonnummer och e-postlänk
- Sticky CTA-knapp på mobil
